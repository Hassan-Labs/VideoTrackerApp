# Video Tracker Application

A desktop management application built using **C# WinForms** and **SQL Server**, following a clean **3-Tier Architecture** (Presentation, Business Logic, and Data Access Layers).

## Features
- **Client Management:** Add, edit, and delete client profiles.
- **Project Tracking:** Full CRUD operations for projects, tracking durations, prices, statuses, and delivery dates.
- **Data Integrity:** Strict relational constraints between clients and projects.
- **Dynamic UI:** Smart data-bound controls, dynamic ComboBox binding, and validation.

## Tech Stack
- **Language:** C#
- **Framework:** .NET Windows Forms
- **Database:** Microsoft SQL Server
- **Data Access:** ADO.NET (SqlClient)
- **Architecture:** 3-Tier Architecture Pattern
